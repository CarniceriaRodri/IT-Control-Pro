IT Control Pro · Capturas OCR

Fotografía → texto editable → GitHub privado → ordenador

1. Fotografiar o seleccionar

Selecciona imágenes del móvil. El OCR se procesa en el navegador del teléfono.

Las fotografías no se enviarán a GitHub hasta que pulses «Enviar a GitHub». Se eliminarán los metadatos de la imagen al preparar la copia JPEG.

2. Revisar y corregir el texto

Corrige el OCR antes de guardarlo. También puedes descargar las fotos y los TXT directamente sin usar GitHub.

3. Enviar a GitHub privado

Se enviará cada fotografía junto a su archivo de texto OCR para poder descargarlos desde Windows.

Solo pruebas autorizadas. No utilices imágenes, códigos de equipos, capturas o documentación corporativa real sin aprobación de Sistemas y Seguridad. Un repositorio privado de GitHub no equivale a almacenamiento corporativo autorizado.

El token solo se mantiene en la memoria de esta página durante el envío. No se incluye en archivos, URL ni configuraciones. Debes utilizar un repositorio privado independiente, no el repositorio público de IT Control Pro.

En el ordenador Windows

Entra con tu cuenta en el repositorio privado de GitHub. Abre capturas/, selecciona la carpeta correspondiente y descarga la foto y el archivo .txt de cada captura.

Esta herramienta es independiente del servidor local de IT Control Pro para Windows. No sincroniza automáticamente los datos del inventario con GitHub.
